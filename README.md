# Proteus Engineering Projects

This repository contains my electronics circuit designs and Arduino source code.

## Projects Included:
1. **Keypad, LCD, and LED System** - Matrix keypad interfacing with a display.
2. **LDR National Project** - Light-dependent resistor sensor automation.
3. **PIR Relay with LCD** - Motion tracking system controlling a mechanical relay.
4. **Soil Moisture System** - Automatic irrigation sensor controls.

## How to View
- Download the `.pdsprj` files to open them directly inside **Proteus 8 Professional**.
- Open the `.ino` files inside the **Arduino IDE** to view the microcontroller source code.
